Arquitectura y Stack Tecnológico - Gimnasio



Stack

\- \*\*App Móvil:\*\* Flutter (Ligera, reactiva y multiplataforma)

\- \*\*Página Web:\*\* React (Vite + Tailwind CSS, posicionamiento y velocidad)

\- \*\*Base de Datos:\*\* Supabase (PostgreSQL con tiempo real y autenticación)

\- \*\*Pagos:\*\* API QR Directa (BCP / BNB / OpenBCB)



Patrones de Arquitectura

\- \*\*Reserva de Clases:\*\* MVVM / BLoC reactivo (Sincronización de cupos en tiempo real)

\- \*\*Pasarela de Pagos:\*\* MVI (Flujo unidireccional y prevención de doble cobro)

\- \*\*Calendario de Horarios:\*\* Componentes Desacoplados (Filtros sin parpadeo)

\- \*\*Página Web Pública:\*\* Componentes optimizados para carga rápida y SEO
