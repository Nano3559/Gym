Ejercicio: Desarrollo de una página web

para un gimnasio

1\. Objetivo

Desarrollar una página web para la gestión y presentación de un gimnasio, donde los

clientes puedan conocer los servicios, horarios, entrenadores y planes disponibles,

además de poder registrarse y reservar clases.

La página deberá tener una interfaz moderna, clara y adaptable a celulares y

computadoras.

2\. Página principal

Crear una página de inicio que contenga:

• Logo del gimnasio.

• Menú de navegación.

• Imagen principal.

• Nombre y slogan del gimnasio.

• Botón "Inscribirme".

• Botón "Ver planes".

Secciones

• Inicio

• Nosotros

• Servicios

• Planes

• Entrenadores

• Horarios

• Galería

• Contacto

3\. Ejercicio 1 — Sección de servicios

Crear una sección donde se muestren las diferentes actividades del gimnasio.

Por ejemplo:

• Musculación.

• Cardio.

• CrossFit.

• Entrenamiento funcional.

• Spinning.

• Yoga.

• Zumba.

• Entrenamiento personalizado.

Cada servicio debe mostrar:

• Imagen.

• Nombre.

• Descripción.

• Horario.

• Botón "Ver más".

4\. Ejercicio 2 — Planes de membresía

Crear una sección de planes.

Ejemplo:

Plan Básico

• Acceso al gimnasio.

• Lunes a viernes.

• Horario limitado.

• Precio mensual.

Plan Completo

• Acceso ilimitado.

• Todas las clases.

• Lunes a sábado.

• Precio mensual.

Plan Premium

• Acceso ilimitado.

• Todas las clases.

• Entrenador personalizado.

• Evaluación física.

• Precio mensual.

Cada tarjeta deberá tener un botón:

"Elegir este plan"

5\. Ejercicio 3 — Registro de cliente

Crear un formulario para que una persona pueda registrarse.

Solicitar:

• Nombre.

• Apellido.

• CI.

• Fecha de nacimiento.

• Teléfono.

• Correo electrónico.

• Dirección.

• Plan seleccionado.

• Contacto de emergencia.

El formulario deberá validar que los campos obligatorios estén completos.

6\. Ejercicio 4 — Horarios

Crear una página o sección donde el cliente pueda consultar las clases.

Ejemplo:

Hora Lunes Martes Miércoles Jueves Viernes

07:00 CrossFit Yoga CrossFit Yoga Funcional

09:00 Spinning Zumba Spinning Zumba Spinning

18:00 Funcional CrossFit Funcional CrossFit Funcional

20:00 Yoga Spinning Yoga Spinning Yoga

Cada clase deberá mostrar:

• Nombre.

• Entrenador.

• Hora.

• Capacidad disponible.

• Botón "Reservar".

7\. Ejercicio 5 — Reserva de clases

Cuando el usuario presione "Reservar", deberá poder:

1\. Iniciar sesión o registrarse.

2\. Seleccionar la clase.

3\. Seleccionar fecha.

4\. Confirmar reserva.

Después de confirmar deberá aparecer:

Reserva realizada correctamente.

También deberá existir una sección:

Mis reservas

Donde el usuario pueda ver:

• Clase.

• Fecha.

• Hora.

• Entrenador.

• Estado.

Y cancelar una reserva.

8\. Ejercicio 6 — Entrenadores

Crear una sección con los entrenadores del gimnasio.

Cada entrenador deberá tener:

• Fotografía.

• Nombre.

• Especialidad.

• Experiencia.

• Horarios.

• Botón "Ver perfil".

Ejemplo:

Carlos Pérez

Entrenador funcional y musculación.

María López

Especialista en yoga y movilidad.

9\. Ejercicio 7 — Panel administrativo

Crear un panel privado para el administrador del gimnasio.

El administrador deberá poder consultar:

Dashboard

• Clientes registrados.

• Membresías activas.

• Membresías por vencer.

• Clases del día.

• Reservas del día.

• Ingresos del mes.

10\. Ejercicio 8 — Gestión de clientes

Crear una tabla:

Cliente CI Teléfono Plan Inicio Vencimiento Estado

El administrador podrá:

• Ver cliente.

• Editar cliente.

• Eliminar cliente.

• Ver membresía.

• Renovar membresía.

Estados:

• Activa.

• Por vencer.

• Vencida.

11\. Ejercicio 9 — Gestión de

membresías

El administrador deberá poder:

• Crear planes.

• Modificar planes.

• Cambiar precios.

• Definir duración.

• Activar/desactivar planes.

Ejemplo:

PLAN: PREMIUM

Precio: Bs. 300

Duración: 30 días

Acceso: Ilimitado

Clases: Todas

Entrenador personal: Sí

12\. Ejercicio 10 — Control de asistencia

Crear una pantalla para registrar la asistencia de los clientes.

El sistema deberá permitir buscar al cliente mediante:

• Nombre.

• CI.

• Código de membresía.

Mostrar:

Cliente: Juan Pérez

Plan: Premium

Membresía: Activa

Vencimiento: 25/09/2026

\[ REGISTRAR ASISTENCIA ]

Después deberá quedar registrada:

• Fecha.

• Hora.

• Cliente.

• Entrenador, si corresponde.

13\. Ejercicio 11 — Pagos

Crear una sección para registrar los pagos.

Métodos:

• Efectivo.

• QR.

• Transferencia.

• Tarjeta.

Registrar:

• Cliente.

• Concepto.

• Plan.

• Monto.

• Método de pago.

• Fecha.

Ejemplo:

Cliente: Juan Pérez

Plan: Premium

Monto: Bs. 300

Método: QR

Fecha: 18/08/2026

14\. Ejercicio 12 — Reportes

El administrador deberá poder generar reportes de:

• Clientes.

• Membresías.

• Asistencias.

• Reservas.

• Pagos.

• Ingresos mensuales.

• Clases más reservadas.

También deberá poder filtrar por:

• Día.

• Semana.

• Mes.

• Tipo de membresía.

• Clase.

15\. Ejercicio 13 — Contacto

Crear una sección de contacto con:

• Dirección.

• Teléfono.

• WhatsApp.

• Correo.

• Redes sociales.

• Mapa.

Además, crear un formulario:

Nombre:

Correo:

Teléfono:

Mensaje:

Botón:

Enviar mensaje

16\. Diseño

La página deberá cumplir con:

• Diseño moderno.

• Responsive.

• Buena distribución de información.

• Uso correcto de imágenes.

• Botones claramente identificables.

• Formularios funcionales.

• Navegación sencilla.

• Diseño adaptable a celular.

17\. Entregable final

El alumno deberá entregar una aplicación que tenga como mínimo:

1\. Página de inicio

2\. Servicios

3\. Planes

4\. Horarios

5\. Entrenadores

6\. Registro

7\. Reservas

8\. Login

9\. Panel administrativo

10.Clientes

11.Membresías

12.Asistencias

13.Pagos

14.Reportes

15.Contacto

Flujo principal que debe funcionar

Cliente

→ entra a la página

→ revisa los planes

→ se registra

→ selecciona una membresía

→ consulta horarios

→ reserva una clase

→ asiste al gimnasio

→ se registra su asistencia.

Administrador

→ inicia sesión

→ administra clientes

→ administra membresías

→ administra clases

→ controla reservas

→ registra pagos

→ controla asistencias

→ consulta reportes.



\# Requerimientos del Sistema de Gimnasio (15 Ejercicios)



1\. Página Principal (Hero, slogan, navegación, CTAs)

4\. Ejercicio 3 - Registro de Clientes (CI, fecha nacimiento, contacto emergencia, etc.)

5\. Ejercicio 4 - Horarios y Matriz semanal de clases con cupos

6\. Ejercicio 5 - Reserva de clases y vista "Mis reservas"

7\. Ejercicio 6 - Sección de Entrenadores con experiencia y horarios

8\. Ejercicio 7 - Panel Administrativo Dashboard (Socios activos, ingresos, reservas)

9\. Ejercicio 8 - Gestión y tabla de clientes (CRUD, estados de membresía)

10\. Ejercicio 9 - Gestión de Membresías y precios

11\. Ejercicio 10 - Control de Asistencia en puerta (Búsqueda por CI)

12\. Ejercicio 11 - Registro de Pagos (QR, Efectivo, Transferencia, Tarjeta)

13\. Ejercicio 12 - Reportes con filtros por fecha y clase

14\. Ejercicio 13 - Contacto, redes y mapa

15\. Entregable final y flujo completo Cliente vs Administrador
